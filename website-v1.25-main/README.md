# ITSA SFIT Website

## 🌐 Overview

The official website of the Information Technology Students' Association (ITSA) at St. Francis Institute of Technology (SFIT). The platform serves as a central hub for showcasing departmental activities, technical events, workshops, hackathons, student achievements, and committee initiatives while fostering engagement within the IT student community.

## 🚀 Features

- Responsive and user-friendly design
- ITSA committee information and member profiles
- Event and workshop showcases
- Technical competition and hackathon updates
- Student achievements and success stories
- Announcements and notices
- Contact and communication portal
- Mobile-friendly interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Responsive Web Design

## 🎯 Objectives

- Promote technical learning and innovation
- Encourage student participation in extracurricular activities
- Bridge the gap between academics and industry
- Provide a platform for showcasing student talent and achievements
- Facilitate communication between students and the department
